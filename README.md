# MVC_BGAKADEMI

## Proje Açıklaması
MVC_BGAKADEMI, ASP.NET Core MVC ile geliştirilmiş bir web uygulamasıdır. 
Proje, bir mağaza uygulaması için temel CRUD işlemlerini gerçekleştirir ve katmanlı mimari kullanılarak yapılandırılmıştır.

## Özellikler
- Kullanıcı oturum açma ve kayıt olma
- Ürün listeleme, ekleme, güncelleme ve silme (CRUD işlemleri)
- Kategori bazlı ürün filtreleme
- Yönetici paneli

## Klasör Yapısı
- `.vs`: Visual Studio yapılandırma dosyaları
- `Entities`: Veritabanı modelleri
- `Presentation`: MVC yapısındaki view ve controller dosyaları
- `Repositories`: Veri erişim katmanı
- `Services`: İş mantığı ve servis katmanı
- `StoreApp`: Uygulamanın ana modülleri
